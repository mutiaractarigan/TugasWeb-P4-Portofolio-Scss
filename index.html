// 01 Tentang Saya

Saya adalah mahasiswa semester 3 Program Studi Ilmu Komputer di Universitas Negeri Medan, dengan minat besar pada pengembangan web dan desain antarmuka. Saya senang mempelajari hal baru, terutama seputar HTML, CSS, dan JavaScript, serta bagaimana membangun pengalaman pengguna yang rapi dan mudah diakses.

Di luar perkuliahan, saya sering mengerjakan proyek pribadi kecil untuk mengasah kemampuan coding, mengikuti workshop, dan sesekali berkontribusi pada proyek open-source. Halaman ini dibuat sebagai bagian dari Tugas Rutin 1 mata kuliah Pemrograman Web.
